
# Windows Security Administration

## Project Overview
This project documents a beginner-level Windows 11 security assessment. It demonstrates practical knowledge of Windows security features, protection settings, and basic security administration.

## Project Objectives
- Examine Windows Defender protection.
- Verify real-time protection settings.
- Inspect Windows Firewall status.
- Review Microsoft SmartScreen protection.
- Examine device security features.
- Check Memory Integrity.
- Inspect BitLocker drive encryption status.

## Environment
- Operating System: Windows 11 Pro
- Platform: Personal Windows computer
- Security Tool: Windows Security
- Assessment Type: Defensive Security Assessment

## Security Checks and Findings

| Security Feature | Finding |
|---|---|
| Virus & Threat Protection | No current threats reported |
| Real-time Protection | Enabled |
| Windows Firewall | All profiles active |
| SmartScreen | Enabled |
| Core Isolation | Available |
| Memory Integrity | Enabled |
| TPM Security Processor | Available |
| BitLocker | Off |
| Hardware Security Capability | Standard hardware security not supported |
| Device Encryption | Unavailable |

## Security Observations

The assessment confirmed that several important Windows security protections were enabled.

However, BitLocker was found to be off, and Device Encryption was unavailable. Standard hardware security capability was also reported as unsupported.

These findings identify areas that may require further investigation.

## Recommendations
- Review BitLocker availability and consider enabling drive encryption after backing up important files and safely storing the recovery key.
- Investigate hardware security compatibility.
- Keep Windows security protections enabled.
- Maintain regular system updates.
- Perform periodic security assessments.

## Conclusion
This project provided practical experience in examining Windows security configurations and documenting security findings.

It demonstrates foundational knowledge of defensive security administration and security assessment reporting.
